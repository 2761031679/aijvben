## 回滚方案

如果出现问题，可以通过以下方式回滚：

1. **CSS 回滚**
   ```bash
   # 还原立绘尺寸
   #teahouse-npc { width: 240px; height: 380px; right: 6%; }
   
   # 还原聊天区
   #teahouse-vbox { width: min(500px, 90vw); left: 50%; top: 15%; }
   ```

2. **打字机回滚**
   ```javascript
   // chat.js 第 650 行
   lastMsg._typed = false;  // 改回 false
   ```

3. **语音回滚**
   ```javascript
   // tts.js 第 90 行
   synth.cancel();  // 加回这行
   ```

## 浏览器缓存清理

修改后如果效果不生效，请：
1. 按 `Ctrl+F5` 强制刷新
2. 或打开开发者工具 → Network → 勾选"Disable cache"
3. 或在 URL 后加 `?v=新` 强制重新加载 CSS/JS
